# Google Maps and business data: responsible use

This skill is designed to research prospects, not to scrape or resell Maps data.

## Practical rules

- Use Google Maps as an interactive discovery surface for a focused, user-requested search.
- For an integrated product, use an authorized Google Maps Platform / Places API workflow and request only the fields needed.
- Respect attribution, storage and caching requirements of the applicable Google terms and API documentation.
- Do not bulk-export, scrape, index, rehost or build a durable lead database from Google Maps business names, addresses, ratings, reviews or other Maps content.
- Do not collect data through browser automation intended to bypass normal access, rate limits or terms.
- If a business is discovered on Maps, independently visit its official website before making website-quality claims.
- A business’s own public website, social page or contact page is a better source for a durable proposal note than a copied Maps listing.

## Safe claim language

| Observation | Use this wording | Avoid |
|---|---|---|
| No official site was found after a limited check | “I did not find an independently reachable official website in this check.” | “This business has no website.” |
| HTTP / certificate issue observed | “The site did not load securely over HTTPS when checked on {date}.” | “Your site is unsafe.” |
| Contact action hard to locate | “I could not find a clear contact or WhatsApp action on the homepage.” | “Your site does not convert.” |
| Mobile issue observed | “At a mobile viewport, the menu/text/button presented this issue: …” | “Your website is terrible on mobile.” |

## Source records

For every conclusion, keep:

- source URL
- date/time checked
- page or element checked
- exact observation
- whether it is an observation, a recommendation or a hypothesis

## Official references

- Google Maps Platform terms: https://cloud.google.com/maps-platform/terms
